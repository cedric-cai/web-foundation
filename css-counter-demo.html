CSS 基础

盒模型

盒模型由 content、padding、border、margin 组成。box-sizing: border-box 可以避免宽度溢出。

选择器优先级

ID 选择器 > 类选择器 > 标签选择器，行内样式权重大于内部样式表。

伪类与伪元素

:hover, ::before, ::after 是常用的伪类和伪元素。

布局进阶

Flex 弹性布局

使用 display: flex 可以轻松实现一维布局，justify-content 和 align-items 控制主轴和交叉轴对齐。

Grid 网格布局

Grid 是二维布局系统，fr 单位用于分配剩余空间，适合复杂页面结构。

grid-template-areas

通过命名区域可以直观定义布局模板。

响应式设计

媒体查询

使用 @media 可以根据屏幕宽度应用不同样式，移动优先是常见策略。

相对单位

rem、em、vw、vh 让布局更适应不同屏幕尺寸。
